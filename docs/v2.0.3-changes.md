# LinzinDeskClock 2.0.3：使用者選擇時鐘位置

## 行為

- 設定「雙區塊：時鐘固定在左／右」決定內容位置。
- 拖曳分隔線只調整左右區域大小；時鐘即使變成較小區域，也不會自動換邊。
- 切換時鐘左右位置保留當前分隔比例，不會將比例鏡像或重設為 70/30。
- 30%、50%、70% 放開吸附、20–80% 拖曳範圍及 UI Lock 維持原規則。
- 儲存的左右選擇及比例各自還原；舊版已有的有效左右選擇會保留，缺少資料時才使用舊版面設定作為預設。
- 三語設定與引導文字改為時鐘位置，移除「左大／右大」描述。版本為 2.0.3 / code 5。

此變更依使用者 2026-11-08 的後續要求，取代原需求「時鐘自動占較大區域」。2.0.2 媒體、行程、電量、防烙印行為保留。
