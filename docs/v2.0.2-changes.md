# LinzinDeskClock 2.0.2

## 功能與修正

- 底部退出手勢區由 32 dp 縮為 12 dp，可見提示條為 36 × 2 dp；保留向上滑動退出與右上角退出按鈕。
- 鎖屏時完整顯示曲名、演出者、封面及進度，並保留已授權的上一首、播放／暫停、下一首及拖曳進度。移除舊的隱藏媒體選項，忽略既有 `auto_hide_media` 值；只有使用者明確啟用 UI Lock 時才停用操作。
- 媒體控制面板維持底部配置，通常占高度 35%，依可用空間調整但不超過 40%。正常高度可直接看到所有主要控制；極短畫面或放大字體可在面板內捲動。
- 移除控制面板頂部的第二層圓角裁切，消除封面與面板接縫的黑色缺口，保留整個播放器外框圓角。
- 進度軌道及圓點共用同一組座標；點擊、拖曳、鍵盤與無障礙操作均使用相同端點。切歌或啟用 UI Lock 時取消未完成的拖曳。
- 點擊行程項目可開啟可捲動的詳細資訊，顯示完整標題、開始／結束時間、地點、行事曆名稱及說明；也可開啟系統行事曆中對應的行程或重複行程時段。需先授予行事曆權限並解鎖裝置。
- 新增「低電量保護」：預設未接上電源且電量低於 20% 時降低亮度，門檻可設為 5–50%，動作可選關閉、自動降低亮度或退出時鐘。降低亮度僅將時鐘視窗亮度限制在 8%，不提高原先更低的手動亮度、不改系統亮度設定；接上電源或電量恢復後還原。退出會結束時鐘並停止監看；仍符合低電量退出條件時，引導頁恢復前景或服務重新啟動也不會恢復監看。充電、電量恢復或改變保護動作後，可重新開啟 App 或從設定恢復。
- 保留 2.0.1 的 30/50/70% 分隔吸附、通知存取權設定入口、一般手機鎖定觸發與折疊螢幕 30°–120° 行為。

## 程式結構

媒體面板與進度條分離為 `ui/MediaPlayerPanel.kt`、`ui/MediaSeekBar.kt` 與純座標邏輯 `media/SeekGeometry.kt`。行事曆查詢、格式化與 Intent 分離在 `calendar/`，搭配 `ui/SideDateWidget.kt` 及 `ui/CalendarEventDetailsDialog.kt`。低電量判斷與儲存位於 `power/`，設定入口為 `settings/LowBatterySettingsSection.kt`，由共用 `DeskClockScreen` 管理視窗亮度與退出回呼。`LowBatteryMonitorGuard` 在 Activity 恢復前景及 Service 啟動時讀取電池狀態，避免低電量退出後被背景恢復路徑重新啟動。

本版未增加外部套件或 Android 權限；繁體中文、簡體中文及英文資源同步更新。

## 實機後續檢查

本輪未在實體手機執行 App，因此 OEM 自動喚醒、鎖屏播放控制及實際行事曆外部 App 的效果仍待使用者操作確認。已有的自動時鐘設定與限制請見 `v2-user-guide.md` 及 `v2-device-checklist.md`。

## 媒體控制區防烙印確認（2026-11-08）

現有 2.0.2 已在 `DeskClockScreen` 最外層套用 `checkerboardBurnInProtection`，因此雙面板中的整個媒體播放器都在效果範圍內。開關預設開啟；實體手機只讀檢查也確認 `pref_burn_in_enabled=true`、系統 API 37，沒有開啟 App 或更動手機設定。

Android 13／API 33 以上，無觸控 60 秒後套用棋盤格遮黑，之後每 300 秒交換遮黑像素；觸碰重設閒置計時，媒體播放狀態更新不重設。API 31–32 現有函式直接略過此效果。效果若因繪圖例外失敗，現有程式會移除 RenderEffect，因此僅從程式結構不能證明每部 OEM 裝置實際繪圖結果。

新增 `MediaBurnInProtectionTest`，在隔離 API 35 模擬器使用實際 `DeskClockScreen`、Android MediaSession 及 1280×720 硬體視窗 PixelCopy 驗證；以 Compose 虛擬時間推進 60 秒／5 分鐘計時，不是實機長時間顯示測試。結果 `OK (2 tests)`，14.857 秒：

- 封面、玻璃控制面板、曲名、演出者、時間、進度軌道、上一首／播放／下一首都有約一半可見像素被遮黑。
- 5 分鐘後遮黑的像素集合交換；媒體進度更新期間效果保持。
- 真實觸控下一首成功送達 MediaSession，畫面恢復，之後再次閒置會重新啟用保護。
- 關閉防烙印設定時，閒置後媒體區不出現棋盤格遮黑。

最終測試建置：`.local/burn-in-build-final.log`；測試結果：`.local/burn-in-instrumentation-final.log`；八張原始截圖：`.local/burn-in-images/burn-in-verification/`。早期失敗紀錄保留於同目錄，失敗原因為新測試的 Compose 清理方式／虛擬時鐘同步，修正僅在測試程式內。正式程式碼與已安裝 APK 均未變更，沒有 CI、手機啟動或手機重新安裝。此確認限於渲染效果覆蓋與運作，不代表長期 OLED 耐久測試或不烙印保證。
